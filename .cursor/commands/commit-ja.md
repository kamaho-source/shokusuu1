# 日本語でコミットメッセージを生成する

ステージ済みの差分（`git diff --cached`）を確認し、**日本語**の Conventional Commits 形式でコミットメッセージを提案する。

## 必ず守ること

1. `.cursor/rules/commit-message-format.mdc` に従う
2. サマリ・本文は日本語。プレフィックス（`feat:` / `fix:` 等）のみ英語
3. 1行目は50文字以内を目安。必要なら箇条書き本文を付ける
4. ユーザーが明示依頼しない限り、こちらで `git commit` は実行しない

## 出力

- そのまま使えるコミットメッセージ全文を提示する
- 複数案は出さず、1案に絞る
