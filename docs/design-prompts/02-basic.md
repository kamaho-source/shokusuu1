# プロンプト: 基本設計書

前掲の共通システム指示に従い、次の **基本設計書** を作成してください。

## 含める章立て（必須）

1. 文書メタと上位/下位文書リンク
2. 機能一覧（機能ID付き）
3. 画面設計（遷移図・各画面の入出力・メニュー条件）
4. API 設計（パス / Method / パラメータ / レスポンス概要 / エラー）
5. 認可設計（権限マトリクス・Policy 対応）
6. データ設計（追加カラム・参照テーブル・セッション）
7. 処理フロー（集計表示 / Excel / 権限更新のシーケンス）
8. Excel 出力仕様（ファイル名・シート概要）
9. 集計ルール（基本。式の詳細は詳細設計へ）
10. コンポーネント配置
11. エラーハンドリング方針
12. テスト観点
13. 改訂履歴

## トーン

実装着手可能な仕様粒度。エンドポイントと画面項目は具体名で書く。
