## 目的

本ページは、概要設計書・基本設計書・詳細設計書の生成に用いた **プロンプト原文** を監査・再現可能に残すための記録です。

## 生成フロー（要約）

1. Backlog 課題本文と（任意）実装を入力にする  
2. `docs/design-prompts/00-system.md` を共通指示として適用  
3. 対象種別に応じて以下を適用する  
   - 仕様書: `05-specification.md`  
   - 設計書: `01-overview.md` / `02-basic.md` / `03-detailed.md`  
4. 本記録とプロンプト原本ファイルを Backlog ドキュメント / 課題添付に公開する
