# プロンプト: 機能仕様書

前掲の共通システム指示に従い、次の **機能仕様書（仕様書）** を作成してください。

設計書（概要／基本／詳細）より前段の「何を作るか」を定義する。実装方式の細部は設計書へ委ねる。

## 含める章立て（必須）

1. 文書メタ（文書ID / 対象機能 / 版 / 作成日 / 課題キー）
2. 文書の目的と関連文書（設計書へのリンク想定）
3. 背景・目的
4. 用語定義
5. 対象範囲（In / Out）
6. アクター（利用者・外部システム）
7. 機能要件一覧（要件ID付き。優先度があれば記載）
8. 画面・操作仕様（画面が無い機能は「画面なし」と明記し、代わりにトリガ／操作主体を書く）
9. 入出力・外部インタフェース（API・Webhook・ファイル等）
10. 業務ルール・制約
11. 非機能要件（性能・セキュリティ・可用性・運用）
12. 前提条件・依存
13. 受け入れ条件（チェックリスト）
14. 改訂履歴

## トーン

PO・実装者・テスターが同じ理解を持てる粒度。「〜であること」の要件文を明確に書く。
推測は「想定」と明示する。
