# プロンプト: 概要設計書

前掲の共通システム指示に従い、次の **概要設計書** を作成してください。

## 含める章立て（必須）

1. 文書メタ（文書ID / 対象機能 / 版 / 作成日 / 課題キー）
2. 文書の目的と関連文書
3. 背景と課題
4. 目的（箇条書き）
5. スコープ（In / Out）
6. 利用者と利用シーン
7. 全体構成（Mermaid 論理図）
8. 主要設計方針（認可 / 可視化 / 集計 / 永続化 / アーキ位置づけ）
9. 画面構成（概要レベル）
10. 外部依存
11. 非機能要件（概要）
12. リスクと対策
13. 受け入れ条件（概要）
14. 改訂履歴

## トーン

経営・PO・他チームが読む粒度。クラス名・SQLは詳細設計に委ね、方針と境界を明確にする。
