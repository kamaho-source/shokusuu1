# プロンプト: 詳細設計書

前掲の共通システム指示に従い、次の **詳細設計書** を作成してください。

## 含める章立て（必須）

1. 文書メタ
2. ファイル構成（パス一覧）
3. ルーティング詳細
4. DI / 認可マップ
5. クラス詳細（定数・公開/私有メソッド・例外処理）
6. 集計アルゴリズム（effective フラグ・使用率式・除外/削除条件）
7. DB 詳細（マイグレーション・Entity accessible）
8. 権限更新 API 詳細（監査ログ action 含む）
9. 画面 JS 詳細（状態変数・レース防止・SRI・Excelシート列）
10. メニュー実装条件
11. エラーコード一覧
12. セッションキー詳細
13. セキュリティチェックリスト
14. シーケンス（必要に応じ Mermaid）
15. 将来拡張（対象外の明記）
16. 改訂履歴

## トーン

実装とレビューの正本。メソッド名・フィールド名・式をコードと一致させる。
不一致がある場合は「実装優先」で記載し、差分を注記する。
